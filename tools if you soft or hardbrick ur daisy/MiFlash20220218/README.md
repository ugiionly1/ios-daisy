# IF YOU SOFT BRICKED YOUR DAISY:

-1st: boot into Fastboot mode
-2nd: enter XiaoMiFlash.exe
-3rd: if you dont have drivers download it
-4th: get the stock rom SPECIFICALLY FASTBOOT ROM SHOULD BE LATEST
-5th: connect your Mi A2 Lite on pc should be detected
-6th: flash the stock rom
-7th: (optional) if you want clean install and locking the bootloader use flash_all_lock.bat
-8th: wait
-9th: in a bit it should be done
-10th: done!🤑🤑🤑🤑🤑🤑

# IF YOU HARD BRICKED YOUR DAISY

-1st: prayers for your Mi A2 Lite
-2nd: jk get the Qualcomm HS-USB QDLoader 9008 Drivers from https://qdloader.com/
-3rd: download the drivers and restart the pc should detect as QUSB_BULK OR Qualcomm HS-USB QDLoader 9008
-4th: get a tweezer and put it in to the test point located left of the battery connector

-9th: (optional) if you want clean install and locking the bootloader use flash_all_lock.bat
-10th: wait
-11th: in a bit it should be done
